# 快速上手

本文档带你从零跑通第一个检测项目：**标注 → 训练 → 测试**。

## 0. 准备数据

把待标注图片放入一个文件夹（支持 jpg / jpeg / png / bmp / webp，含子文件夹）。

## 1. 标注

1. 打开主界面（`run_main.bat`），点击「标注平台」卡片；
2. 菜单「文件 → 打开目录」选择图片文件夹；
3. 按 `Q` 新建多边形 / 按 `W` 新建矩形（沿右侧栏按钮亦可）；第一次标注会提示创建类别文件（labels.txt）；
4. AI 辅助（可选，需先按 README 放置 SAM 权重到 `weights/sam/`）：
   - 按 `S`：智能多边形——左键点目标，实时预览轮廓，右键撤销锚点，回车确认；
   - 按 `B`：画笔模式——左键笔画塑形（并集）、右键挖除（差集）；
   - 按 `L`：对当前图执行智能标注；「工具 → AI 批量预标注」可整目录批量；
5. 标注结果自动保存为图片同名 `.json`（labelme 格式）。

## 2. 训练

1. 回主界面，点击「训练平台」卡片 →「新建项目」：
   - 填项目名，选择数据集目录（第 1 步的图片文件夹）与模型输出目录；
   - 选择任务类型：分类 / 目标检测 / 实例分割；
2. 进入项目 → 选模型（检测推荐 `yolo11n`，分割推荐 `yolo11n-seg` 或 `maskrcnn18`，分类推荐 `resnet18`）；
3. 「快速配置」模式会按数据情况推荐参数；需要细调时切换「专家模式」（增强策略、工业优化、训练加速、切图训练等）；
4. 点击「开始训练」，在训练可视化页查看损失与 mAP 曲线；训练完成后在项目模型目录产出 `best.pt`。

> 样本太少？先用「缺陷样本合成」卡片把缺陷贴图融合到良品图上扩充数据，再回到训练平台。

## 3. 测试

1. 主界面点击「测试平台」卡片；
2. 上方选择项目 →「加载该项目最新模型」（或「选择权重文件…」直接选 `.pt`）；
3. 「打开图片… / 打开文件夹…」选择待测图片，A / D 键切换上下张；
4. 调节置信度 / IOU 滑条实时查看效果；「批量运行…」可对整个文件夹推理并导出：
   - `检出结果/`：每图一个 JSON（统一契约 / labelme / COCO 可选）；
   - `可视化/`：渲染图；
   - `摘要.json`：每类检出数与耗时统计。

大幅面图片（如 4K）勾选「4K 大图分块推理」可显著提升小目标检出。

## 4. 流程图（AI + 通用算子）

主界面左侧导航点「流程图」（与 AI 平台同级）：
1. 「选择文件夹」指定待处理图片目录（图片树可预览）；
2. 「模型目录」选择存放流程 JSON 的目录，「新建」创建空白流程，或选择已有流程 / 模板；
3. 「编辑流程」打开画布：从左侧节点库拖入 **AI 算子**（目标检测 / 实例分割 / 分类 / 逐图推理）
   与 **通用算子**（裁图、网格分块、结果合并、检出过滤、逻辑判定、输出）连线；
   模型节点需在属性面板选择 `.pt` 权重；
4. 「运行流程」对单图执行并在右侧看结果；「批量运行」对整个目录执行并导出结果；
5. 「打包流程」把流程与模型封入单个 `.xvap`，便于拷贝到其他机器复用。

## 常见问题

- **首次训练很慢 / 卡在下载**：训练首次会从官方源下载预训练权重（YOLO / torchvision），
  离线环境请提前在有网机器下载并放入 `weights/` 目录（参见 `xccv/engine/offline.py` 注释）；
- **AI 智能标注按钮提示缺权重**：按 README 把 SAM 权重放到 `weights/sam/`；
- **训练报类别不一致**：迁移学习权重必须与当前数据集类别一致；
- **显存不足**：调小批量大小（batch_size），或开启「冻结骨干」「轻量掩码头」等加速选项。
